# Centro de Gestión de Integrantes

Panel administrativo privado de La Movida SST Plus para consultar, filtrar y actualizar la base internacional de integrantes.

- Autenticación: Supabase Auth
- Autorización: administrador activo del módulo Ranking
- Datos: funciones RPC protegidas; no se expone `service_role`
- Incluye bitácora de cambios y control de reintentos de correo

Sitio: https://movidasst.github.io/gestion/
